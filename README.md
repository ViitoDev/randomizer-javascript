# Randomizer

A simple web app that draws unique random numbers within a user-defined range. Built as a practice challenge from Alura's *Lógica de programação* course.

## Features

- Draw a custom quantity of unique numbers
- Define a numeric range (from / to)
- Input validation (non-numeric values, inverted ranges, quantity larger than range)
- Reset button to clear inputs and results

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started

Clone the repository and open `index.html` in your browser:

```bash
git clone <repo-url>
cd (paste name)
```

Then double-click `index.html` or serve the folder with any static server.

## Project Structure

```
randomizer/
├── app.js        # randomizer logic
├── index.html    # markup
├── style.css     # styling
└── README.md
```

## How It Works

1. Enter how many numbers you want to draw.
2. Set the lower (`From`) and upper (`To`) bounds.
3. Click **Draw** — the app generates unique random numbers within the range.
4. Click **Reset** to start over.
